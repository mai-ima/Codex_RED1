# SUZAKU UI/Vercel Audit — 2026-07-13

## 総合評価: 88 / 100

静的HTMLのみで222生成ページを構成し、外部画像ゼロ・ビルド不要・Vercel clean URLs対応まで整っている点は非常に強い。製品、ストア、サポート、法務、開発者、管理モックまで情報設計が広く、ブランドの視覚言語も一貫している。

## 加点ポイント

- **ブランド/UI一貫性: 22 / 25** — 朱・金・黒を軸にしたトークン設計、カード、メガメニュー、ヒーロー、チャート表現が統一されている。
- **情報設計: 18 / 20** — 主要導線、製品比較、検索、サポート、ストア、法務まで揃い、架空企業サイトとしての網羅性が高い。
- **静的/Vercel適性: 18 / 20** — clean URLs、trailingSlash、immutable asset cache、`.vercelignore` による内部ファイル除外が適切。
- **アクセシビリティ: 16 / 20** — スキップリンク、alt、h1/main構造、aria-live、ARIA tabsなどの基礎がある。今回、モバイルドロワーの展開状態と動的ページのh1を補強した。
- **保守性: 14 / 15** — `scripts/gen.py` と `src/pages/` の分離、データ単一ソース、キャッシュバスティングが明確。

## 主な改善内容

- モバイルドロワーの各アコーディオンに `type="button"`、`aria-expanded`、`aria-controls`、パネルIDを追加し、スクリーンリーダーとキーボード操作時の状態把握を改善。
- ドロワー開閉JSを状態同期型に変更し、Escapeキーで閉じる・リンク遷移時に閉じる挙動を追加。
- 動的描画中心のニュース記事ページとドキュメントビューアに視覚非表示h1を追加し、全生成HTMLの主要構造監査を通過。
- Vercel配信用ヘッダーに `Permissions-Policy` と `X-DNS-Prefetch-Control` を追加し、ブラウザ権限面と名前解決最適化を補強。
- Playwright未導入環境で全ページ監査スクリプトが不明瞭なスタックトレースで落ちないよう、探索パスと導入案内を追加。

## 残課題

- Playwright依存が環境に存在しない場合、視覚的な横スクロール/壊れ画像/コンソール監査は実行できない。CIまたはローカルで `npm i -D playwright` を入れて常時監査するのが望ましい。
- トップページや製品詳細は非常にリッチなため、LCP計測とモバイルでのスクロール負荷計測を追加するとさらに安心。
- インラインstyleが多く、将来Next.js化する場合は頻出レイアウトをCSSユーティリティまたはコンポーネントへ寄せると移行が楽になる。
