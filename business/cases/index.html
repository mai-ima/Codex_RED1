CASE 01 — eスポーツ施設

esports HUB SHIBUYA 様(東京・120台導入)

モバイル部門の常設大会環境としてSUZAKU 3を120台導入。「陣」のプロファイル一括配布により、大会ごとの端末設定作業が従来の3時間から15分に短縮。連戦でも熱によるフレーム低下が発生せず、「機材差への抗議がゼロになった」と運営チーム。

導入構成SUZAKU 3 ×120 / 氷嵐クーラー ×120 / 大会用プロファイル配布ツール
効果大会設営時間 -92% / 熱起因のリプレイ申請 0件 / 機材トラブルによる中断 0回

CASE 02 — 教育機関

学校法人 燕学園 様(神奈川・450台導入)

タブレット更新でTSUBAME Pad 2を450台導入。キッズスペースによる利用制限とMDMでの一括管理により、情報担当教員の管理工数を月40時間削減。6年のセキュリティ更新保証が「更新サイクルを7年に伸ばせる」と評価されました。

導入構成TSUBAME Pad 2 ×450 / MDM構築 / 延長保守5年(バッテリー交換込み)
効果端末管理工数 -40時間/月 / 破損率 従来端末比 -63% / 授業アプリ起動時間 半減

CASE 03 — 映像制作

株式会社ホムラフィルム 様(大阪・35台導入)

ロケ撮影のBカメ・現場プレビュー用にSUZAKU 4を導入。8K/30fps撮影と大盤デスクトップでの即時確認により、現場でのラフ編集が可能に。夏場の炎天下ロケでも録画停止が起きない点が採用の決め手でした。

導入構成SUZAKU 4 ×35 / SUZAKU Dock ×10 / 法人延長保守3年
効果撮影データの現場確認時間 -70% / 熱停止による撮り直し 0件 / 機材運搬量 -30%

CASE 04 — 物流・倉庫

つばめ流通サービス 株式会社 様(埼玉・280台導入)

庫内のピッキング・検品用ハンディ端末をTSUBAME 3に統一。高輝度ディスプレイと堅牢ケースで、冷凍倉庫から屋外積み込みまで1台で対応。バーコード読取アプリの起動と連続スキャンが速く、1シフトあたりの処理件数が向上しました。

導入構成TSUBAME 3 ×280 / 業務用堅牢ケース / MDM一括管理 / 法人保守5年
効果ピッキング処理 +18%/時 / 端末バッテリー切れによる交換 -75% / 管理工数 -44%

CASE 05 — 医療・介護

医療法人 朱鷺会 様(福岡・160台導入)

病棟での電子カルテ参照・バイタル入力端末としてTSUBAME Pad 2を導入。FeliCa対応による職員認証と、抗菌仕様の運用、そして落下に強い設計を評価。キッズスペース機能を応用した「患者説明モード」でインフォームドコンセントにも活用されています。

導入構成TSUBAME Pad 2 ×160 / 抗菌カバー / MDM(持ち出し制限) / 法人保守5年
効果記録入力の待ち時間 -37% / 端末破損率 -58% / 認証時間 従来比 -60%

CASE 06 — 建設・現場

雷建設 株式会社 様(北海道・90台導入)

図面確認・遠隔臨場・写真管理用にSUZAKU Neo 3を導入。手袋対応タッチと防塵防滴、そして高負荷の点群ビューアでも持続する処理性能が現場で評価。真夏・真冬の屋外でも安定動作します。

導入構成SUZAKU Neo 3 ×90 / 現場管理アプリ連携 / 法人保守3年

CASE 07 — 官公庁・自治体

燐光市役所 様(公共・520台導入)

窓口・災害対応・議会タブレットとしてTSUBAME 3およびTSUBAME Pad 2を導入。国内設計・長期セキュリティ更新・国内サポート体制が調達基準に適合。災害時にはテザリング拠点として運用する事業継続計画にも組み込まれています。
